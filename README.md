# 💥 ABRAHAM KABLOK!

Duelos de bloques en primera persona: 1 vs 1, 2 vs 2 y 3 vs 3, con tienda de armas, misiones, ruleta, cajas sorpresa y modo en línea con amigos.

**Jugar:** https://abrahamdaza.github.io

- En computador: teclado y ratón.
- En celular o tablet: controles táctiles. Usa "Agregar a pantalla de inicio" para instalarlo.
- En línea: toca **🌐 EN LÍNEA**, crea una sala y manda el código a tus amigos.
